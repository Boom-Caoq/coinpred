# JEV 怎么工作、置信度是什么

**Languages:** [简体中文](jev.md) · [English](../en/jev.md)

页面原文：[JEV 模型说明](https://coinpred.com/zh/news/jev-model/)（更新于 2026-10-26）

JEV 负责「此刻方向更偏哪一边」。它不是 K 线生成模型，也不是 TradingView 自动信号。

## 模型基于什么

JEV 是 [TypeSafe AI](https://typesafe.ai/) 的 System One 模型。它接收一段上下文和预先定义好的问题，返回可供程序使用的结构化结果：选项（Choice）、评分（Score）和对应概率。官方训练方法是 **RLCD**（Reinforcement Learning for Calibrated Decisions，面向校准决策的强化学习），强调决策输出和不确定性表达。

来源：[TypeSafe · Introducing Jev](https://typesafe.ai/blog/introducing-system-one-models-and-jev)（站点资料核对日期 2026-09-23）

和「写一篇长分析」的通用大模型不同，JEV 只能在我们定义的选项里选择，并给出每个选项的概率。结果因此更容易统一展示，也更容易事后核对。

## 每次分析输入了什么

点击「开始分析」后，Coinpred 服务端会把下面这些数据整理成一份结构化行情上下文。这是产品设计选择：**指标计算交给代码，综合判断交给模型**。因为官方也提示 JEV 存在数值精度、复杂间接推理等已知局限，所以指标一律先算好再送给模型。[来源：JEV 1.13 已知局限](https://docs.typesafe.ai/model-jaggedness/jev-1.13)

1. **200 条历史 K 线与成交量**（Binance 现货；周期由你选择：1m、5m、15m、1h、4h、1d）。
2. **12 项由程序计算的技术指标**
   - 趋势：EMA20、EMA50、SMA200、ADX
   - 动量：RSI(14)、MACD(12, 26, 9)、Stochastic(14, 3)、CCI(20)、Williams %R(14)
   - 波动：ATR(14)、布林带 Bollinger(20, 2)
   - 量能：OBV
3. **实时盘口深度**（WEEX 订单簿前 15 档买卖盘）。
4. **近期成交流**（WEEX 最近成交，用来观察主动买卖力量）。

还要记住两件边界：

- 输入描述的是**现货**行情；所选 K 线周期是观察粒度，**不等于**事件合约到期时间。
- 请求里**没有绑定**某一份合约的执行价、结算规则或赔付比例，所以输出只是技术方向参考。

## 五档方向怎么定义

| 方向 | 判定标准（概述） |
| --- | --- |
| 强烈看涨 | 趋势、动量、订单簿与近期成交流强烈一致偏多 |
| 偏多 | 证据中度偏多，但存在部分分歧或确认不足 |
| 中性 | 证据混杂、偏弱或相互冲突，没有可靠的方向优势 |
| 偏空 | 证据中度偏空，但存在部分分歧或确认不足 |
| 强烈看跌 | 趋势、动量、订单簿与近期成交流强烈一致偏空 |

「中性」是正当结论。证据冲突时，模型被允许、也被鼓励说「看不清」。

## 置信度模型是什么

根据 TypeSafe 官方说明，Choice 与 Score 会返回各选项的概率分布，并据此计算一个 **0–1 的 confidence**：分布越集中，判断越明确；越分散，不确定性越大。[TypeSafe · Confidence](https://docs.typesafe.ai/confidence)

需要严格区分的几点：

- 官方公开文档**没有披露具体公式**，所以这里不会把「最高选项概率」或「熵」写成官方算法。
- Coinpred 显示的是方向问题直接返回的 `confidence × 100%`；模型没返回时显示「—」。
- **方向置信度**、**独立评分问题的置信度**、**最高方向概率**是三个不同的量，不能混用。

## 置信度 ≠ 胜率

这是最重要的一条，也是站点原文口径：

**方向置信度衡量的是这次分类有多确定，不能直接解释为事件合约的获胜概率。** 即使显示 80%，也不代表这类交易已有 80% 的历史胜率。

要得到真正的「胜率」，需要固定预测时点、到期规则和结算价格，做样本外验证，并比较基线、校准曲线和 Brier 分数，还要计入成本与赔付。**本站目前没有发布这类 JEV 验证结果。**

因此：不要因为置信度高就下单。置信度只告诉你「这一次的概率是否集中」，不告诉你「这种单过去赢了多少」。

## 分析依据和观察建议从哪来

JEV 不生成自由文本长报告。

- 「分析依据」由程序根据输入数据整理，例如价格相对均线的位置、MACD 转向、盘口深浅。
- 「观察建议」是模型从预设选项里选出（例如「等待确认」「关注回踩」「控制下行风险」「关注阻力位」「保持中性」），再匹配到预设文案。

它们**不代表模型内部的推理过程**。要把一次结论当第二意见，先看概率分布的形状，再看这些依据是否和你自己在图上看到的一致。

## 正确用法

- 把 JEV 当作结构化的第二意见，而不是交易信号。
- 分布集中在一个方向，说明证据较一致；分布散开，说明行情本身不清晰。
- 结合自己的到期时间、赔付比例和仓位上限做决定。
- 和融合控制台、清算地图一起看时，仍要遵守 [决策清单](decision.md)。
